
# 03-03｜Linux 使用者、群組和檔案權限

## 本課目標
理解 Linux 為什麼區分使用者和管理員，並能看懂最基本的檔案權限。

## 1. 使用者是什麼？
Linux 可以有多個使用者帳號。每個帳號有自己的識別資訊、家目錄和權限。

```bash
whoami
id
```
whoami 顯示目前使用者；id 顯示 UID 和群組資訊。

## 2. 看懂 ls -l
```bash
ls -l
```
可能看到：
```text
-rw-r--r-- 1 kali kali 12 Nov 23 10:00 note.txt
```
最前面的權限字串中，第一個字元代表檔案類型；之後三組分別是擁有者、群組和其他使用者的權限。
r = 讀取，w = 寫入，x = 執行。

## 3. 權限數字
- r = 4
- w = 2
- x = 1
因此 7 = 讀寫執行；6 = 讀寫；5 = 讀取和執行；4 = 只讀。

例如 644 通常代表擁有者可讀寫，群組和其他人只可讀。

## 4. 在自己的練習檔觀察
```bash
cd ~/cyber-practice/files
touch permission-demo.txt
ls -l permission-demo.txt
chmod 600 permission-demo.txt
ls -l permission-demo.txt
```
chmod 600 讓擁有者可讀寫，其他人沒有權限。只對自己建立的練習檔執行。

## 5. sudo 是什麼？
sudo 允許有相應授權的使用者，以更高權限執行指定命令。高權限操作可能改變系統設定、安裝軟體或刪除資料；不要因為命令報錯就習慣性加 sudo。

## 6. 最小權限原則
Least Privilege（最小權限）表示使用者和程式只應取得完成工作所需的最低權限。把所有檔案設成 777 可能造成安全問題。

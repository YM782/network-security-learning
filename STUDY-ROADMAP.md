# Network Security Study Roadmap（网络安全系统学习路线）

A 12-month roadmap for roughly 10–12 study hours per week. The schedule is a guide, not a guarantee; extend any stage until its checkpoints are met.
建议每周约 10–12 小时，按 12 个月规划。时间仅供参考；未达到阶段目标时应延长学习时间。

## Month 1 — Computer fundamentals（第1个月：计算机底层）

**Theory（理论）**
- CPU, registers, caches, RAM, storage, buses（CPU、寄存器、缓存、内存、存储和总线）.
- BIOS/UEFI and boot process（BIOS/UEFI 与启动过程）.
- Processes, threads, virtual memory, paging（进程、线程、虚拟内存和分页）.
- Kernel mode, user mode, system calls, interrupts（内核态、用户态、系统调用和中断）.
- Filesystems and drivers（文件系统和驱动）.

**Commands（命令）**
```bash
uname -a
lscpu
free -h
lsblk
ps aux
journalctl -b
```

**Lab（实验）:** Inspect CPU, memory, disks, processes, and boot logs in your own Linux VM.
**Checkpoint（验收）:** Explain how a program is loaded, scheduled, and given memory.

## Month 2 — Linux and Windows administration（第2个月：Linux 与 Windows）

- Users, groups, permissions, ACLs（用户、组、权限和 ACL）.
- Processes, services, startup, scheduled tasks（进程、服务、启动和计划任务）.
- Filesystems, logs, package management（文件系统、日志和软件包管理）.
- PowerShell and Bash basics（PowerShell 与 Bash 基础）.

**Commands（命令）**
```bash
id
find
grep
chmod
chown
systemctl
journalctl
```
```powershell
whoami /all
Get-Process
Get-Service
Get-NetTCPConnection
Get-NetIPConfiguration
```

**Lab:** Create a test user, adjust permissions, inspect a service, and compare Linux and Windows logs.
**Checkpoint:** Diagnose a simple permission or service-start failure.

## Month 3 — Computer networking（第3个月：计算机网络）

- OSI and TCP/IP models（OSI 与 TCP/IP 模型）.
- Ethernet, MAC, ARP, IPv4/IPv6, subnetting（以太网、MAC、ARP、IP 和子网划分）.
- DNS, DHCP, NAT, routing, switching（DNS、DHCP、NAT、路由和交换）.
- TCP handshake, UDP, ports（TCP 握手、UDP 和端口）.
- HTTP/HTTPS and TLS basics（HTTP/HTTPS 与 TLS 基础）.

**Commands（命令）**
```bash
ip -br addr
ip route
ip neigh
ss -tulpn
nslookup example.com
curl -I https://example.com
```

**Lab:** Capture DNS and TCP handshake traffic generated by your own test machine in Wireshark.
**Checkpoint:** Explain how a browser resolves a domain and establishes an HTTPS connection.

## Month 4 — Programming and automation（第4个月：编程与自动化）

- Python basics, functions, modules, exceptions（Python 基础、函数、模块和异常）.
- File handling, regular expressions, JSON, CSV（文件、正则、JSON 和 CSV）.
- Bash and PowerShell automation（Bash 和 PowerShell 自动化）.
- SQL basics and C memory concepts（SQL 基础和 C 语言内存概念）.

**Labs:** Build a log parser, a file-integrity checker, and a script that summarizes your own lab scan output.
**Checkpoint:** Read, modify, and explain a small script.

## Month 5 — Security fundamentals（第5个月：网络安全基础）

- Confidentiality, integrity, availability（机密性、完整性和可用性）.
- Authentication, authorization, least privilege（认证、授权和最小权限）.
- Hashing, symmetric and asymmetric cryptography（哈希、对称和非对称加密）.
- TLS certificates and digital signatures（TLS 证书和数字签名）.
- CVE, CVSS, threat, vulnerability, risk（CVE、CVSS、威胁、漏洞和风险）.
- Firewalls, IDS/IPS, logging, incident response（防火墙、入侵检测/防御、日志和事件响应）.

**Checkpoint:** Explain the difference between a vulnerability, an exploit, a threat, and a risk.

## Month 6 — Network analysis and asset discovery（第6个月：网络分析与资产识别）

- Wireshark display filters and protocol analysis（Wireshark 显示过滤器和协议分析）.
- Nmap host discovery and service identification in an owned lab（在自有实验网络中进行主机发现和服务识别）.
- DNS, HTTP, TLS, and packet troubleshooting（DNS、HTTP、TLS 和数据包排错）.
- Read vendor advisories and map versions to known issues（阅读厂商公告并核对软件版本风险）.

**Lab command（实验命令）**
```bash
nmap -sV -oN lab-scan.txt <LAB_TARGET_IP>
```
Replace the placeholder only with the IP of your own isolated lab target.
仅将占位符替换为自己隔离靶场中的目标 IP。

**Checkpoint:** Produce an asset and service inventory with evidence and scope.

## Month 7 — Web foundations（第7个月：Web 基础）

- HTTP methods, headers, status codes（HTTP 方法、请求头、状态码）.
- Cookies, sessions, authentication（Cookie、会话和认证）.
- HTML, JavaScript, browser security basics（HTML、JavaScript 和浏览器安全）.
- REST APIs, JSON, CORS（REST API、JSON 和 CORS）.
- Reverse proxies and server-side request flow（反向代理和服务端请求流程）.

**Lab:** Use browser developer tools and Burp Suite Community to inspect requests to a local demo application.
**Checkpoint:** Explain a complete request/response cycle.

## Month 8 — Web application security（第8个月：Web 应用安全）

Study the causes, impact, verification, and defenses for:
- SQL injection（SQL 注入）.
- Cross-site scripting / XSS（跨站脚本）.
- CSRF（跨站请求伪造）.
- SSRF（服务端请求伪造）.
- Broken access control / IDOR（访问控制缺陷和不安全直接对象引用）.
- File upload and path traversal（文件上传和路径遍历）.
- Authentication and session weaknesses（认证与会话缺陷）.
- API security（API 安全）.

**Labs:** Use WebGoat, OWASP Juice Shop, and PortSwigger Academy only in their intended training environments.
**Checkpoint:** Write a finding with reproduction steps, impact, evidence, and remediation.

## Month 9 — Host security（第9个月：主机安全）

- Linux services, permissions, sudo, logs（Linux 服务、权限、sudo 和日志）.
- Windows accounts, services, registry, event logs（Windows 账户、服务、注册表和事件日志）.
- Secure configuration and patch management（安全配置和补丁管理）.
- Backup, hardening, endpoint monitoring（备份、加固和终端监控）.

**Checkpoint:** Harden a test VM and document before/after configuration.

## Month 10 — Active Directory and enterprise networks（第10个月：活动目录与企业网络）

- Domain controller, users, groups, Group Policy（域控制器、用户、组和组策略）.
- LDAP, Kerberos, DNS, SMB（LDAP、Kerberos、DNS 和 SMB）.
- Domain trust and access control（域信任和访问控制）.
- Network segmentation and enterprise logging（网络分段和企业日志）.

**Lab:** Build or use GOAD-Light / MINILAB in an isolated virtual network.
**Checkpoint:** Draw the domain topology and explain authentication and authorization flows.

## Month 11 — Authorized end-to-end assessment（第11个月：授权综合测试）

- Define scope, rules of engagement, and test accounts（定义范围、测试规则和测试账户）.
- Inventory assets and services（整理资产和服务清单）.
- Validate findings safely（安全验证发现的问题）.
- Preserve evidence and avoid unnecessary impact（保留证据并避免不必要影响）.
- Prioritize risk and recommend remediation（评估风险并提出修复建议）.

**Checkpoint:** Complete a test report for a deliberately vulnerable lab.

## Month 12 — Reporting and portfolio（第12个月：报告与作品集）

Produce:
1. Lab topology（实验网络拓扑）.
2. System and network notes（系统与网络笔记）.
3. Reproducible lab instructions（可复现实验步骤）.
4. Troubleshooting records（故障排查记录）.
5. Security findings and remediation guidance（安全发现与修复建议）.
6. A final assessment report（最终安全测试报告）.

## Weekly study balance（每周时间分配）

| Activity（学习内容） | Hours（小时） |
|---|---:|
| Theory and documentation（理论与文档） | 3 |
| Commands and coding（命令与编程） | 2 |
| Hands-on labs（动手实验） | 4 |
| Troubleshooting and notes（排错与笔记） | 2 |

## Lab report template（实验报告模板）

For every lab, record:
- Objective（实验目的）
- Environment and network scope（实验环境与网络范围）
- Theory（理论原理）
- Commands and configuration（命令与配置）
- Expected output（预期输出）
- Actual output（实际输出）
- Errors and troubleshooting（错误与排查）
- Security impact（安全影响）
- Defensive measures（防御措施）
- Sources（资料来源）

Never scan or exploit systems without explicit authorization. Keep intentionally vulnerable targets isolated and never commit passwords, tokens, private keys, or VPN subscription URLs.
未经明确授权，不扫描或利用任何系统。故意存在漏洞的靶机必须隔离；不要将密码、令牌、私钥或 VPN 订阅链接提交到仓库。


# 07 — 網路安全工具入門

## 課程順序
1. [01 Wireshark 第一次封包觀察](01-Wireshark-First-Capture.md)
2. [02 Nmap 只掃描自己的 localhost](02-Nmap-Localhost.md)
3. 後續學 Burp Suite：先理解 HTTP，再觀察自己的測試網站。
4. Goby：先熟悉資產清單和授權範圍。
5. Metasploit：理解漏洞、隔離靶場和授權後再學。
6. Wazuh：放在防禦與日誌監控階段。
7. Cobalt Strike：商業紅隊平台，屬於後續專業階段，必須遵守官方授權。

工具輸出不是結論；必須理解輸入範圍、結果含義、誤報可能性和對目標的影響。

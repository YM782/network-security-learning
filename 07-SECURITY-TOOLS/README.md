
# 07 — 網路安全工具入門：先知道用途，再學操作

## 工具不是學習的起點

先學電腦、Linux 和網路，再使用工具。工具只會幫你觀察或測試，不會自動讓你理解結果。

## 1. 初期工具地圖

| 工具 | 中文用途 | 先學什麼 | 現在是否要深入 |
|---|---|---|---|
| Wireshark | 網路封包分析 | IP、TCP/UDP、DNS、HTTP | 可以先學基本觀察 |
| Nmap | 網路主機、連接埠和服務盤點 | IP、連接埠、TCP | 先只測 localhost 和自己的靶場 |
| Burp Suite Community | 觀察和測試 Web 請求 | HTTP、Cookie、Session | Web 基礎後開始 |
| Goby | 網路資產識別與安全檢查 | IP、服務、授權範圍 | 先了解介面，不要掃描陌生網路 |
| Metasploit Framework | 安全測試框架 | 網路、漏洞、靶場管理 | 初級基礎完成後 |
| Wazuh | 安全監控與日誌分析 | Windows/Linux 日誌 | 防禦學習階段 |
| Cobalt Strike | 商業化紅隊模擬與安全評估平台 | 網域、端點、攻防流程 | 高階階段；不是現在的入門工具 |

## 2. Wireshark：先觀察自己的網路流量

你可以先開啟 Wireshark，選擇自己正在使用的網路介面，開始擷取，然後在自己的瀏覽器開啟一個普通網站，再停止擷取。

先辨認：

- DNS：網域名稱查詢。
- TCP：傳輸控制協定。
- TLS：加密連線相關資訊。
- HTTP：網站請求與回應（若流量未加密）。

只觀察自己有權限擷取的流量，不要擷取其他人的私人通訊。

## 3. Nmap：只從本機開始

Nmap 用來檢查指定目標的網路服務。初學時只測自己的本機回送位址：

```bash
nmap 127.0.0.1
```

這個命令的目標是自己的電腦。輸出可能因為本機是否有服務正在監聽而不同。

在理解 IP、連接埠和掃描範圍前，不要把目標改成陌生網站或不屬於自己的網段。

## 4. Burp Suite：觀察自己測試網站的請求

Burp Suite Proxy 可以讓瀏覽器請求經過代理工具，方便查看請求方法、路徑、標頭、Cookie 和回應。

初期只連接自己建立的本機測試網站或授權靶場。不要攔截他人帳號、私人資料或不屬於你的網路流量。

## 5. Metasploit 和 Cobalt Strike

它們不是初學者用來「試試看能不能打進去」的軟體。

學習前必須先理解：

- 測試授權和範圍。
- 目標作業系統與網路服務。
- 漏洞成因和修補方式。
- 實驗靶場隔離。
- 日誌、證據與報告。

Cobalt Strike 是商業平台，使用與取得方式應遵守官方授權。現階段先不安裝、不配置，也不需要下載來路不明的破解版本。

## 6. 工具學習的固定格式

每次學一個工具，都要回答：

1. 它解決什麼問題？
2. 它讀取什麼資料？
3. 它會不會改變目標狀態？
4. 哪些人可以授權我使用？
5. 我在自己的實驗環境如何操作？
6. 如何解讀結果？
7. 如何確認沒有影響其他設備？

## 7. 本課驗收

你不需要現在熟練所有工具。先能把 Wireshark、Nmap、Burp、Goby、Metasploit、Wazuh、Cobalt Strike 的用途分清楚，並知道哪些應該晚一點再學。

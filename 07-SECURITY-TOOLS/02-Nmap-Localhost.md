
# 07-02｜Nmap 只掃描自己的 localhost

## 本課目標
了解 Nmap 是什麼、掃描目標是什麼，以及如何在不碰觸其他設備的情況下查看自己的本機服務。

## 1. Nmap 是什麼？
Nmap 是網路探索和安全稽核工具，常用於了解授權範圍內的主機和網路服務。掃描結果需要解讀，不能把工具顯示的每一項都當成漏洞。

## 2. localhost 是什麼？
localhost 通常指向本機回送位址。IPv4 常見位址是 127.0.0.1。它指向目前這台電腦，不是家庭路由器或陌生網路設備。

## 3. 先查看本機監聽服務
```bash
ss -tuln
```
這會顯示本機 TCP/UDP 監聽連接埠。

## 4. 執行本機掃描
```bash
nmap 127.0.0.1
```
目標只指定本機回送位址。若沒有服務，結果可能顯示沒有開放連接埠，這不代表 Nmap 故障。

## 5. 理解輸出
- open：連接埠上有服務接受連線。
- closed：目標可回應，但目前沒有服務在該連接埠監聽。
- filtered：掃描無法確定狀態，可能受到過濾或防火牆影響。

## 6. 安全邊界
不要把目標改成不屬於你的 IP、公司網段、公共網站或公共 Wi-Fi 中的設備。只有明確授權的範圍才可測試。

## 7. 本課驗收
能解釋 Nmap、localhost、open、closed 和 filtered，並能對照 ss 和 Nmap 的結果。

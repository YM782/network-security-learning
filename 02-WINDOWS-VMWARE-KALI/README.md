
# 02 — Windows、VMware 與 Kali Linux

## 本課目標

認識三個不同的東西：實體電腦、虛擬機軟體、虛擬機中的 Kali Linux。

## 1. 三個名詞

- Host（宿主機）：你真正使用的 Windows 電腦。
- VMware（虛擬機軟體）：在 Windows 裡模擬另一台電腦的軟體。
- Guest（客體系統）：安裝在虛擬機裡的 Kali Linux。

可以把 VMware 想成一個虛擬房間：Windows 是整棟房子，Kali 是房間裡的一台虛擬電腦。虛擬機有自己的虛擬 CPU、記憶體、硬碟和網路卡。

## 2. 為什麼安全學習使用虛擬機？

1. 可以建立獨立練習環境。
2. 可以做 Snapshot（快照），在實驗出錯後回到先前狀態。
3. 可以把靶場與日常 Windows 環境隔開。
4. 可以練習 Linux，不必把 Windows 換掉。

快照不是完整備份；重要檔案仍應另外保存。

## 3. 先認識 VMware 網路模式

| 模式 | 白話意思 | 初學建議 |
|---|---|---|
| NAT | Kali 透過宿主機的網路連出去 | 一般上網和下載更新常用 |
| Host-only | Kali 與宿主機或同一虛擬網段溝通，通常不直接連外 | 建立隔離靶場時優先考慮 |
| Bridged | Kali 像一台實體電腦直接加入目前區域網路 | 初學者不要拿來連接故意有漏洞的靶場 |

**安全原則：** 不要把有漏洞的練習機使用 Bridged 模式接入家庭、公司或公共網路。正式搭建靶場前，先確認每台虛擬機的網卡模式。

## 4. 建立快照

在關閉或暫停虛擬機、確認狀態穩定後：

1. 在 VMware 選取 Kali 虛擬機。
2. 開啟 Snapshot 管理功能。
3. 建立一個快照。
4. 名稱例如 `clean-kali-before-lab`。
5. 之後做大型設定變更前，再建立一個新快照。

不同 VMware 版本的選單名稱可能不同。建立快照前先確認磁碟空間。

## 5. Kali 第一次開啟時做什麼？

先不要安裝一堆滲透工具。先確認系統能正常工作：

```bash
whoami
pwd
uname -a
cat /etc/os-release
```

這些命令分別查看目前使用者、所在目錄、核心與系統版本。

## 6. Windows 和 Kali 的基本分工

- Windows：日常使用、瀏覽器、文件、下載與管理 VMware。
- Kali：Linux 命令列、網路觀察、安全工具和隔離實驗。
- VMware：管理虛擬機、快照和網路模式。

不要把 Kali 當成「按一個按鈕就能入侵」的工具。工具必須建立在作業系統和網路基礎上。

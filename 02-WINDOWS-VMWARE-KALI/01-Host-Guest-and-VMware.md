
# 02-01｜宿主機、虛擬機和 VMware

## 本課目標
理解 Windows 如何透過 VMware 運行 Kali Linux。

## 1. 三個名稱
- Host（宿主機）：安裝 VMware 的實體電腦，這裡通常是 Windows。
- VMware：使用宿主機資源建立虛擬電腦的軟體。
- Guest（客體系統）：安裝在虛擬機中的 Kali Linux。

## 2. 虛擬機不是另一台實體電腦
VMware 會提供虛擬 CPU、記憶體、硬碟和網卡。Windows 把部分資源分配給 VMware，Kali 再於虛擬環境中使用它們。
如果分配太多記憶體給 Kali，Windows 和 Chrome 可能變慢；分配太少，Kali 也可能運行不順。

## 3. 虛擬磁碟
Kali 在虛擬機內看到自己的磁碟，但底層通常是一組保存在 Windows 硬碟上的虛擬磁碟檔案。不要直接刪除不理解的虛擬磁碟檔案。

## 4. Snapshot（快照）
快照記錄虛擬機某個時間點的狀態，方便實驗出錯時回復。
快照不是完整備份：它會佔用磁碟空間，快照鏈也需要管理。重要文件仍要另外備份。

## 5. 實際觀察
在 VMware 選取 Kali，查看虛擬 CPU 數量、記憶體、虛擬硬碟容量和網路介面模式。先查看，不急著修改。

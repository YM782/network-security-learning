
# 02-02｜VMware 的 NAT、Host-only 和 Bridged

## 本課目標
理解虛擬機的三種常見網路模式，知道用途和安全邊界。

## 1. NAT 模式
NAT（Network Address Translation，網路位址轉換）模式下，虛擬機通常透過宿主機提供的網路連線存取外部網路。常用於 Kali 更新和一般學習。NAT 不代表完整安全隔離。

## 2. Host-only 模式
Host-only（僅主機）通常建立宿主機和虛擬機之間的私有虛擬網路，適合不需要連外的本機練習。實際隔離程度仍需檢查 VMware 和 Windows 設定。

## 3. Bridged 模式
Bridged（橋接）讓虛擬機像另一台實體設備加入目前的區域網路。它可能接觸家庭、公司或公共網路中的其他設備。初學者不要用它連接故意有漏洞的靶場。

## 4. 模式比較
| 模式 | 通常可否連外 | 常見用途 |
|---|---|---|
| NAT | 可以 | 一般上網和更新 |
| Host-only | 通常不直接連外 | 隔離的本機實驗 |
| Bridged | 可以，並加入實體 LAN | 特定受控網路用途 |

## 5. Kali 查看網路
```bash
ip addr
ip route
```
ip addr 查看介面和 IP；ip route 查看路由表。網卡名稱可能是 eth0、ens33 或其他名稱，不要假設每台相同。

## 6. 安全原則
故意有漏洞的靶場應按官方文件隔離，不要暴露到公網，不要橋接到家庭或公司網路。實驗前建立快照。

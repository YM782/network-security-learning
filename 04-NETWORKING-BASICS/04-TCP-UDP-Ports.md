
# 04-04｜TCP、UDP 和連接埠

## 本課目標
知道 TCP 和 UDP 的基本差異，理解連接埠為什麼存在，並能查看自己電腦的監聽連接埠。

## 1. 為什麼需要 TCP 和 UDP？
IP 負責把資料送往網路目的地；傳輸層協定則提供不同的資料傳送方式。

## 2. TCP 是什麼？
TCP（Transmission Control Protocol，傳輸控制協定）提供連線導向的傳輸服務，具有確認、重傳和排序等機制。可把它理解為會努力確認資料交付並維持順序的方式。

## 3. UDP 是什麼？
UDP（User Datagram Protocol，使用者資料包協定）提供較簡單的資料報傳送，不像 TCP 一樣保證交付和順序。常見應用包括 DNS 查詢、即時影音和部分遊戲通訊。

## 4. Port（連接埠）是什麼？
一台電腦可能同時運行網站、遠端登入和其他網路程式。連接埠讓作業系統把收到的資料交給正確服務。
| Port | 常見用途 |
|---|---|
| 22 | SSH |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |
這些只是常見慣例，服務可以使用其他連接埠。

## 5. Windows 查看連線
```powershell
netstat -ano
```
可看到本機位址、遠端位址、狀態和 PID。不要把所有連線都視為可疑。

## 6. Kali 查看監聽連接埠
```bash
ss -tuln
```
-t = TCP；-u = UDP；-l = 監聽；-n = 顯示數字，不做名稱解析。

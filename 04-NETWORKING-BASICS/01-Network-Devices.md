
# 04-01｜網路設備和家用網路

## 本課目標
能畫出簡單家用網路，知道電腦、網卡、交換器、路由器和網際網路之間的關係。

## 1. 網路是什麼？
Network（網路）是讓設備互相交換資料的連線系統。家中的手機、筆電、平板和電視透過 Wi-Fi 或網路線連接，就能互相通訊或連上網際網路。

## 2. 五個常見元件
| 名稱 | 繁體中文 | 基本用途 |
|---|---|---|
| Network Adapter | 網路介面卡 | 連接有線或無線網路 |
| Switch | 交換器 | 連接同一區域網路的設備 |
| Router | 路由器 | 在不同 IP 網路之間轉送資料 |
| Access Point | 無線基地台 | 提供 Wi-Fi |
| Modem / ONU | 數據機／光纖終端設備 | 連接電信業者接入網路 |

家用設備可能把路由器、交換器和 Wi-Fi 基地台整合在同一台機器裡。

## 3. LAN 和 WAN
- LAN：區域網路，例如家裡或辦公室。
- WAN：廣域網路，連接較遠的網路。
- Internet：由許多網路互相連接形成的全球網際網路。

## 4. 簡化家用網路流程
```text
筆電／手機
    ↓ Wi-Fi 或網路線
家用路由器
    ↓
電信業者網路
    ↓
Internet
    ↓
網站伺服器
```
實際網路可能經過多個交換器、路由器和其他設備。

## 5. 實際觀察
在 Windows PowerShell 輸入：
```powershell
ipconfig
```
找出目前正在使用的網路介面，觀察 IPv4 Address 和 Default Gateway。

## 二、IP 位址是什麼？

IP（Internet Protocol，網際網路協定）是網路層協定。IP 位址用於識別網路介面在 IP 網路中的邏輯位置，讓封包能依照路由資訊往目的網路傳送。

IPv4 位址長度為 32 位元，通常寫成四組十進位數字，中間用點分隔，例如：

    192.168.1.20

每一組稱為一個 octet（八位元組），範圍是 0 到 255。這個格式只是人類容易閱讀的表示方式，電腦內部使用二進位處理。

## 三、私有 IPv4 位址

家庭和企業內部常用私有 IP。三個私有 IPv4 範圍：

| CIDR 範圍 | 位址範圍 |
|---|---|
| 10.0.0.0/8 | 10.0.0.0–10.255.255.255 |
| 172.16.0.0/12 | 172.16.0.0–172.31.255.255 |
| 192.168.0.0/16 | 192.168.0.0–192.168.255.255 |

私有 IP 通常不會直接作為全球 Internet 的公有路由位址。家用路由器常透過 NAT，讓多台使用私有 IP 的設備共享外部連線。

注意：172.16.0.0/12 不是所有 172.x.x.x 位址。只有 172.16 到 172.31 的範圍屬於這段私有位址空間。

## 四、公有 IP 和私有 IP 的差別

- 私有 IP：用於內部網路，可能在不同家庭或公司重複使用。
- 公有 IP：由網際網路路由系統使用，需符合位址分配和路由規則。
- NAT：常見於家用路由器，負責在內部位址和外部位址之間轉換。

不要把「看到 192.168 開頭」當成唯一安全判斷。網路安全還要看路由、防火牆、服務和實際授權範圍。

## 五、子網路遮罩 Subnet Mask

子網路遮罩用來區分 IP 位址中的網路部分和主機部分。

例子：

    IP Address:   192.168.1.20
    Subnet Mask:  255.255.255.0

這個例子相當於 /24，表示前 24 位元是網路前綴，後 8 位元是主機部分。

同一個 /24 網段的常見位址範圍：

- 網路位址：192.168.1.0
- 一般主機位址：192.168.1.1 到 192.168.1.254
- 廣播位址：192.168.1.255

這是一般 IPv4 /24 網段的基本例子。某些特殊網路和特殊前綴長度有不同規則。

## 六、CIDR 是什麼？

CIDR（Classless Inter-Domain Routing，無類別域間路由）使用斜線和數字表示網路前綴長度。

例子：

    192.168.1.20/24

/24 表示前 24 位元屬於網路前綴。它等價於常見遮罩 255.255.255.0。

其他常見對照：

| CIDR | 子網路遮罩 |
|---|---|
| /8 | 255.0.0.0 |
| /16 | 255.255.0.0 |
| /24 | 255.255.255.0 |
| /25 | 255.255.255.128 |
| /26 | 255.255.255.192 |

初學時先熟悉 /24 和 /16，之後再學如何計算不同網段的可用主機範圍。

## 七、Default Gateway（預設閘道器）

當電腦要傳送資料到本地子網路以外的目的地時，通常會把封包交給預設閘道器。

在家用網路中，預設閘道器通常是路由器的 LAN 位址，例如 192.168.1.1（僅為示例）。

如果電腦有 IP 卻沒有正確的預設閘道器，可能仍能和同一子網路中的設備通訊，但無法正常連接其他網路。

## 八、同一網段和不同網段的基本判斷

假設：

    電腦 A：192.168.1.20/24
    電腦 B：192.168.1.30/24

兩者的網路前綴相同，通常位於同一個 /24 子網路。

另一個例子：

    電腦 A：192.168.1.20/24
    電腦 C：192.168.2.30/24

兩者位於不同 /24 子網路，通常需要透過路由器轉送資料。

實際能否通訊仍取決於路由、防火牆和設備設定。

## 九、Windows 實驗：查看自己的 IPv4 設定

開啟 PowerShell：

    ipconfig /all

找到目前使用的 Wi-Fi 或 Ethernet 介面，記錄：

- IPv4 Address
- Subnet Mask
- Default Gateway
- DHCP Enabled
- DNS Servers

如果有多個介面，例如 VMware 虛擬網卡、VPN 虛擬網卡和 Wi-Fi，請分別記錄，不要把它們混為一談。

## 十、Kali 實驗：查看 IP 和路由

    ip addr
    ip route

ip addr 查看各網路介面的位址；ip route 查看路由表。

如果要查看某個介面的詳細資訊，可以使用：

    ip addr show

這會列出介面資訊。若要指定介面，請先從 ip link 或 ip addr 的輸出確認真實介面名稱，不要直接假設是 eth0。

## 十一、常見故障排查

**問題 1：IP 顯示 169.254.x.x。**

在 Windows 中，這通常是 IPv4 Link-Local 位址，可能代表 DHCP 沒有成功提供一般網路設定。檢查 Wi-Fi／網路線、DHCP 伺服器和路由器狀態。

**問題 2：有 IP，沒有 Default Gateway。**

可能是 DHCP 設定不完整、靜態 IP 配置錯誤，或目前網路本來就不需要外部路由。先確認網路環境，不要直接填入猜測的閘道器位址。

**問題 3：Windows 有 IP，Kali 沒有 IP。**

這可能是 VMware 虛擬網卡、DHCP 或網路模式問題。先查看 VMware Network Adapter，再於 Kali 執行 ip addr 和 ip route。

**問題 4：IP 看起來相同，但設備不能互通。**

還要檢查子網路遮罩、VLAN、路由、防火牆和服務監聽狀態。只看 IP 前三組數字不能在所有情況下判斷是否同一網段。

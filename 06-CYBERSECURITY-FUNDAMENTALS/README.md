
# 06 — 網路安全基本概念

## 本課目標

先理解安全工作究竟在保護什麼，以及「威脅、漏洞、風險、攻擊」有什麼差別。

## 1. 資訊安全是什麼？

資訊安全（Information Security）是保護資訊和系統，避免資料被未授權讀取、修改、破壞或中斷。

最常見的基本模型是 CIA Triad：

| 英文 | 中文 | 白話例子 |
|---|---|---|
| Confidentiality | 機密性 | 不該看的人不能看到你的私人資料 |
| Integrity | 完整性 | 沒有授權的人不能偷偷修改資料 |
| Availability | 可用性 | 需要使用系統時，系統能正常提供服務 |

## 2. 威脅、漏洞、風險和攻擊

| 名稱 | 意思 | 例子 |
|---|---|---|
| Threat | 威脅 | 可能造成損害的人、事件或情況 |
| Vulnerability | 漏洞 | 系統中可被利用的弱點 |
| Exploit | 利用方式 | 利用某個弱點造成特定效果的方法 |
| Risk | 風險 | 威脅利用漏洞造成損害的可能性與影響 |
| Attack | 攻擊 | 對系統或資料採取未授權行動 |

例子：一個網站沒有正確檢查使用者權限，這可能是漏洞；有人試圖讀取不屬於自己的資料，這是攻擊行為；資料外洩造成的損失則是風險影響。

## 3. 身分驗證和權限控制

- Authentication（身分驗證）：確認你是誰，例如密碼、通行金鑰或多因素驗證。
- Authorization（授權）：確認你可以做什麼，例如只能讀取自己的訂單。
- Least Privilege（最小權限）：只給使用者完成工作所需的最低權限。

登入成功不代表可以任意查看所有資料。

## 4. 加密和雜湊

- Encryption（加密）：使用金鑰把資料轉換成未持有正確金鑰者不易理解的形式，通常可以解密還原。
- Hashing（雜湊）：把資料轉成固定長度摘要，常用於完整性檢查和密碼儲存設計；一般雜湊不是加密，不能當成可逆保護。

不要把 Base64 當成加密。它只是編碼方式。

## 5. 常見安全威脅

- Phishing（網路釣魚）：誘騙使用者交出帳密或執行危險操作。
- Malware（惡意軟體）：設計來造成未授權行為或損害的軟體。
- Ransomware（勒索軟體）：加密或鎖住資料並勒索。
- Data Breach（資料外洩）：敏感資料被未授權存取或公開。
- Denial of Service（阻斷服務）：讓合法使用者無法正常使用服務。

初期重點是理解原理和防護，不需要自行製作惡意程式或對外部系統發動攻擊。

## 6. 一個簡單的安全分析流程

遇到安全問題時，先問：

1. 需要保護的是什麼資產？
2. 可能有哪些威脅？
3. 系統有什麼弱點？
4. 弱點被利用後可能造成什麼影響？
5. 有哪些控制措施可以降低風險？
6. 如何留下證據，讓別人可以重現和驗證？

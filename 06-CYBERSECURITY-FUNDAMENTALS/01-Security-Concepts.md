
# 06-01｜資訊安全、CIA、威脅和風險

## 本課目標
建立資訊安全的基本思維：保護什麼、可能受到什麼威脅、系統有哪些弱點，以及如何降低風險。

## 1. 資訊安全在保護什麼？
Information Security（資訊安全）保護資料、系統和服務，避免未授權讀取、修改、破壞或中斷。

## 2. CIA 三要素
| English | 繁體中文 | 例子 |
|---|---|---|
| Confidentiality | 機密性 | 不該看到資料的人無法讀取私人文件 |
| Integrity | 完整性 | 未授權者不能偷偷修改資料 |
| Availability | 可用性 | 合法使用者需要時能正常使用服務 |

## 3. 威脅、漏洞、利用和風險
| 名稱 | 解釋 | 例子 |
|---|---|---|
| Asset | 資產 | 帳號、資料庫、電腦、服務 |
| Threat | 威脅 | 可能造成損害的人、事件或情況 |
| Vulnerability | 漏洞 | 系統中可被利用的弱點 |
| Exploit | 利用方式 | 利用弱點造成某種效果的方法 |
| Risk | 風險 | 弱點被利用的可能性及可能影響 |
| Impact | 影響 | 資料外洩、服務中斷或財務損失 |

例子：網站沒有正確檢查使用者權限，可能構成漏洞；有人利用它查看別人的資料，可能造成機密性受損。

## 4. Authentication 和 Authorization
Authentication（身分驗證）確認你是誰，例如密碼或多因素驗證。
Authorization（授權）確認你可以做什麼，例如是否能查看某筆訂單。
登入成功不代表使用者可以讀取所有資料。

## 5. 最小權限和縱深防禦
Least Privilege（最小權限）要求帳號和程式只取得完成工作所需的最低權限。
Defense in Depth（縱深防禦）使用多層防護，例如多因素驗證、更新、防火牆、備份和日誌監控。

## 6. 練習情境
某使用者收到假冒郵件，輸入了公司帳號密碼。請思考：
1. 哪項資產受到影響？
2. 威脅是什麼？
3. 多因素驗證能降低什麼風險？
4. 公司還應採取哪些防護措施？

## 7. 本課驗收
能區分資產、威脅、漏洞、風險和影響，並解釋機密性、完整性、可用性。

# 01 — 認識電腦：從硬體、程序到記憶體安全

> 本模組按「原理 + 操作 + 實驗 + 故障排查 + 真實漏洞案例」學習。不要只背硬體名稱，要能解釋程式在系統中如何執行。

## 本模組目標

能解釋 CPU、RAM、SSD、作業系統、程序、執行緒和記憶體的基本關係；能在 Windows 觀察資源使用，並初步理解核心、驅動程式、指標和物件生命週期為什麼會影響安全。

## 漏洞研究視角

本模組不要求你現在就寫核心漏洞利用程式，而是先學會閱讀記憶體安全問題：

- 指標（Pointer）指向什麼？
- 物件什麼時候建立、什麼時候釋放？
- 釋放後是否仍有其他程式碼保留參照？
- 程序、執行緒和核心驅動程式如何互相作用？
- 為什麼一個上游修補沒有同步到產品，會讓舊設備繼續暴露風險？

## 建議學習方法

- 第一次：閱讀原理，遇到不懂的英文術語先記下來。
- 第二次：打開 Windows，跟著實驗步驟觀察。
- 第三次：閱讀真實案例，畫出物件生命週期。
- 第四次：不看筆記重新解釋漏洞根因。
- 第五次：完成課後測驗，能用自己的話解釋答案。

## 完成檢查

- [ ] 能說明 CPU、RAM、SSD、GPU 和網卡的分工。
- [ ] 能解釋 UEFI、作業系統和應用程式的啟動關係。
- [ ] 能分辨程式、程序、執行緒和 PID。
- [ ] 能在工作管理員查看 CPU、記憶體、磁碟和網路。
- [ ] 能解釋為什麼 VMware/Kali 會使用 Windows 的資源。
- [ ] 能說明指標、物件生命週期和 Use-After-Free。
- [ ] 能解釋 CVE-2019-2215 的核心問題與修補落差。

## 先不要急著學的內容

CPU 暫存器、組合語言、核心原始碼、記憶體管理單元細節、ELF/PE 結構和驅動程式開發都很重要，但需要建立本模組的基礎後，再進入進階底層課程。

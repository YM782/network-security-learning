
# 01 — 認識電腦（Computer Basics）

## 本課目標

學完後，你能說明電腦主要由哪些部分組成、Windows 是什麼、程式如何執行，以及為什麼學網路安全要先認識電腦。

## 1. 電腦是什麼？

電腦可以想成一個依照指令處理資料的系統：

- 輸入：鍵盤、滑鼠、麥克風、網路資料。
- 處理：CPU 執行程式指令。
- 暫存：記憶體保存目前正在使用的資料。
- 儲存：SSD 或硬碟保存檔案。
- 輸出：螢幕、喇叭、網路回應。

例子：你打開瀏覽器看網頁，鍵盤輸入網址，CPU 執行瀏覽器程式，記憶體暫存網頁資料，網路卡收發資料，螢幕顯示結果。

## 2. 五個先認識的硬體

| 名稱 | 中文 | 白話解釋 | 生活比喻 |
|---|---|---|---|
| CPU | 中央處理器 | 執行程式指令、處理資料 | 負責工作的腦袋 |
| RAM | 記憶體 | 暫時放目前正在使用的資料 | 桌面工作空間 |
| SSD/HDD | 固態硬碟／硬碟 | 長期保存 Windows、程式和檔案 | 文件櫃 |
| GPU | 圖形處理器 | 處理圖像、影片和大量平行運算 | 專門處理圖像的工作組 |
| Network Adapter | 網路介面卡 | 讓電腦連接有線或無線網路 | 對外通訊的窗口 |

注意：RAM 不是硬碟。關機後，RAM 中的暫存內容通常會消失；SSD 中保存的檔案仍然存在。

## 3. 硬體和軟體

- Hardware（硬體）：看得到、摸得到的設備。
- Software（軟體）：讓電腦完成工作的程式和資料。
- Operating System（作業系統）：管理硬體、檔案、程序、使用者和應用程式的基本軟體。

Windows、Linux、macOS 都是作業系統。Chrome、Office、Wireshark 是應用程式，不是作業系統。

## 4. 什麼是程式、程序？

- Program（程式）：硬碟中的程式檔，例如瀏覽器的執行檔。
- Process（程序）：程式啟動後，作業系統管理的一個執行實例。
- Thread（執行緒）：程序裡面實際執行工作的一條流程。

初期只要記住：程式像一份工具說明書，程序是把工具拿出來開始工作。後面會再學更精確的差別。

## 5. 在 Windows 看自己的電腦

### 操作 A：看 CPU 和記憶體

1. 在鍵盤按 Ctrl + Shift + Esc。
2. 開啟「工作管理員」。
3. 點「效能」。
4. 分別點 CPU、記憶體、磁碟、Wi-Fi 或乙太網路。
5. 記下 CPU 型號、記憶體容量、磁碟類型和網路狀態。

### 操作 B：查看 Windows 版本

按 Win + R，輸入：

```text
winver
```

按 Enter。這會顯示 Windows 版本資訊。

### 操作 C：查看系統摘要

開啟 PowerShell，輸入：

```powershell
systeminfo
```

這條命令會列出 Windows 版本、開機時間、記憶體和其他系統摘要。第一次輸出很多是正常的。

## 6. 為什麼網路安全要學這些？

安全問題通常發生在某個具體元件或流程：

- 程式有漏洞：需要知道程式如何執行。
- 記憶體錯誤：需要知道 RAM 和程式資料的關係。
- 帳號被盜：需要知道作業系統如何管理使用者。
- 網路被攻擊：需要知道網路卡如何收發資料。
- 惡意程式啟動：需要知道程序和檔案的差別。

現在只要建立基本概念，還不用學 CPU 微架構、暫存器或核心原始碼。

# 01 — 認識電腦：完整基礎教材

> 本模組已按「原理 + 操作 + 實驗 + 故障排查 + 驗收」標準重寫。建議依序學習，不要跳過實驗紀錄。

## 本模組目標

能解釋電腦如何執行程式、管理 CPU 和記憶體、保存檔案、處理網路資料；能在 Windows 工作管理員中觀察資源使用，並對常見卡頓現象提出有根據的排查方向。

## 課程順序

1. [01 電腦的基本組成：從按下電源到打開網頁](01-Computer-Overview.md)
2. [02 CPU、RAM、SSD：電腦為什麼會快、會慢？](02-CPU-RAM-SSD.md)
3. [03 作業系統、程式、程序和執行緒](03-OS-Processes.md)
4. [04 Windows 工作管理員完整實驗：從觀察到初步診斷](04-Task-Manager-Lab.md)

## 建議學習方法

- 第一次：閱讀原理，遇到不懂的英文術語先記下來。
- 第二次：打開 Windows，跟著實驗步驟觀察。
- 第三次：不看命令說明，自己重新操作一次。
- 第四次：完成課後測驗，能用自己的話解釋答案。

## 完成檢查

- [ ] 能說明 CPU、RAM、SSD、GPU 和網卡的分工。
- [ ] 能解釋 UEFI、作業系統和應用程式的啟動關係。
- [ ] 能分辨程式、程序、執行緒和 PID。
- [ ] 能在工作管理員查看 CPU、記憶體、磁碟和網路。
- [ ] 能解釋為什麼 VMware/Kali 會使用 Windows 的資源。
- [ ] 能對一次電腦卡頓提出合理的檢查步驟。

## 先不要急著學的內容

CPU 暫存器、組合語言、核心原始碼、記憶體管理單元細節、ELF/PE 結構和驅動程式開發都很重要，但需要建立本模組的基礎後，再進入進階底層課程。

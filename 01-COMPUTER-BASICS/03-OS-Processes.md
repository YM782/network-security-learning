
# 01-03｜作業系統、程式和程序

## 本課目標
理解 Windows 和 Linux 是什麼，知道程式（Program）和程序（Process）不同，並初步理解作業系統為什麼要管理資源。

## 1. 作業系統是什麼？
Operating System（OS，作業系統）是管理電腦資源的基本軟體，負責協調 CPU、記憶體、檔案、設備、使用者帳號和應用程式。
Windows、Linux 和 macOS 都是作業系統。Chrome、Word 和 Wireshark 是應用程式。

## 2. 程式和程序有什麼不同？
Program（程式）通常指儲存在磁碟上的程式檔或程式碼。
Process（程序）是程式啟動後，由作業系統管理的執行實例。
例子：
1. 桌面上有 Chrome 程式圖示。
2. 點擊圖示，Windows 啟動 Chrome。
3. 工作管理員出現 Chrome 相關程序。
4. 關閉瀏覽器後，相關程序通常結束；某些背景程序可能仍會運行。

一個程式也可能啟動多個程序，因此不能把一個程式和一個程序完全畫上等號。

## 3. 什麼是執行緒？
Thread（執行緒）是程序內部執行工作的流程之一。一個程序可以有多個執行緒。現在只要理解這個關係，不必研究排程演算法或鎖。

## 4. 為什麼作業系統要管理程序？
同時開啟瀏覽器、音樂播放器和 VMware 時，作業系統需要分配 CPU 時間、管理記憶體、協調檔案讀寫和設備使用。

## 5. Windows 實驗
1. 按 Ctrl + Shift + Esc。
2. 在「處理程序」找到 Chrome。
3. 觀察 CPU、記憶體、磁碟和網路欄位。
4. 點「詳細資料」，查看程序名稱和 PID。
PID（Process ID，程序識別碼）是作業系統用來識別程序的數字。不要隨意結束不認識的系統程序。

## 6. Kali 實驗
```bash
whoami
ps
ps aux
```
whoami 顯示使用者；ps 顯示程序；ps aux 顯示較完整的程序清單。

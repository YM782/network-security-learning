
# 01-04｜Windows 工作管理員實驗

## 實驗目標
在自己的 Windows 電腦觀察 CPU、RAM、磁碟、網路和程序，把前面學到的概念與真實設備連起來。

## 實驗前
不需要安裝軟體或管理員權限。只查看資訊，不修改啟動項，也不要結束陌生程序。

## A. 開啟工作管理員
同時按 Ctrl + Shift + Esc。如果是簡化畫面，點「更多詳細資料」。

## B. 查看 CPU
1. 點「效能」→「CPU」。
2. 找到處理器名稱。
3. 觀察使用率、速度和核心資訊。
使用率上下變化通常正常，背景程式也會使用 CPU。

## C. 查看記憶體
1. 點「記憶體」。
2. 記錄總容量、使用中和可用。
Windows 會使用記憶體做快取和系統管理，使用量不等於故障。

## D. 查看磁碟
點「磁碟」，觀察活動時間和讀寫速度。更新、程式載入或背景讀寫都可能令磁碟活動增加。

## E. 查看程序
1. 回到「處理程序」。
2. 找到 Chrome 和 VMware（若正在執行）。
3. 觀察 CPU 和記憶體使用量。
4. 到「詳細資料」查看 PID。

## 常見疑問
- CPU 使用率一直變化：背景服務和使用者操作會讓數字變化。
- 記憶體使用率高：先找出哪個程序使用，不要直接判定中毒。
- Chrome 有很多項目：現代瀏覽器會使用多程序架構處理分頁和擴充功能。

## 本課驗收
能指出 CPU、記憶體、磁碟頁面各自顯示什麼，並解釋 VMware 運行時為何也會消耗 Windows 資源。分享截圖前遮蔽帳號和裝置識別資訊。

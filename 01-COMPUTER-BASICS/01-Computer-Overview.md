# 01-01｜電腦的基本組成：從按下電源到打開網頁

> 難度：初級｜建議時間：60–90 分鐘｜先修：無
>
> 本課不是要求你背硬體名稱，而是要你能解釋：當你按下電源、登入 Windows、打開 Chrome 並訪問網站時，電腦內部大致發生了什麼。

4. 解釋為什麼打開 Chrome 不只是 CPU 一個元件在工作。
5. 在 Windows 工作管理員找到主要硬體的即時狀態。

## 二、先建立整體概念

電腦是一套由硬體（Hardware）和軟體（Software）共同組成的系統。

- 硬體：看得見或摸得到的實體元件，例如 CPU、記憶體、SSD、螢幕和網卡。
- 軟體：讓硬體依照指令工作的程式，例如 Windows、Chrome、驅動程式和安全工具。
- 韌體（Firmware）：儲存在設備中的低階程式，例如主機板 UEFI 韌體。

可以先把電腦想成一間辦公室：

| 電腦元件 | 辦公室比喻 | 實際職責 |
|---|---|---|
| CPU（中央處理器） | 執行工作的員工 | 執行指令、處理資料 |
| RAM（記憶體） | 桌面 | 暫時放置目前工作所需資料 |
| SSD（固態硬碟） | 文件檔案櫃 | 長期保存系統、程式和檔案 |
| 主機板（Motherboard） | 辦公室建築和連接通道 | 讓元件連接並交換資料 |
| GPU（圖形處理器） | 專門處理圖像的團隊 | 加速圖形和大量平行運算 |
| 網卡（Network Adapter） | 對外通訊窗口 | 傳送和接收網路資料 |
| 電源供應器 | 電力系統 | 提供元件所需電力 |

這個比喻只用來建立直覺。真實硬體的工作方式更複雜，不能把比喻當成技術定義。

## 三、七個重要硬體元件

### 1. 主機板 Motherboard

主機板是電腦內部的主要電路板。CPU、記憶體、SSD、顯示卡和其他設備會透過插槽、控制器或連接介面與主機板系統連接。

主機板的重要工作包括：

- 提供元件安裝位置和電氣連接。
- 讓 CPU、記憶體、儲存裝置和周邊設備交換資料。
- 提供 USB、網路、音訊等連接介面。
- 配合韌體完成開機初始化。

筆記型電腦通常把許多元件整合在一塊主機板上，部分記憶體甚至直接焊接，不能像桌上型電腦一樣自由更換。

### 2. CPU Central Processing Unit

CPU 是中央處理器，負責執行程式指令。當你打開瀏覽器、計算檔案雜湊值、解壓縮檔案或執行 Linux 命令時，CPU 都會參與。

先認識幾個概念：

- 核心（Core）：CPU 內可以獨立執行指令流程的運算單元。
- 執行緒（Thread）：作業系統排程的執行單位；硬體執行緒與軟體執行緒是相關但不同的概念。
- 時脈（Clock Speed）：描述時鐘週期的頻率，不等於單獨決定效能的數字。
- 快取（Cache）：容量較小、速度較快的記憶體，用來減少 CPU 等待資料的時間。

初學時不要只看 CPU 百分比或 GHz 就判斷電腦快慢。程式的工作類型、核心數、記憶體、磁碟和散熱都會影響實際表現。

### 3. RAM Random Access Memory

RAM 常翻譯為記憶體或隨機存取記憶體。它用來保存目前正在執行的程式和資料。

例如，你同時開啟 Windows、Chrome、VMware 和 Kali 虛擬機，這些系統與程式都會使用記憶體。RAM 是揮發性記憶體，正常關機後其中的工作資料不會像 SSD 檔案一樣持續保存。

### 4. SSD Solid State Drive

SSD 是固態硬碟，用來長期保存 Windows、應用程式、文件、照片、影片和虛擬機檔案。

SSD 斷電後仍能保存資料。它和 RAM 的用途不同：RAM 主要服務正在執行的工作，SSD 主要保存需要長期保留的資料。

### 5. GPU Graphics Processing Unit

GPU 是圖形處理器。它擅長同時處理大量相似運算，常用於遊戲畫面、影片處理、3D 圖形和部分人工智慧運算。

有些電腦使用整合式 GPU，有些配備獨立顯示卡。不是所有程式都會大量使用 GPU。

### 6. 網路介面卡 Network Adapter

網卡讓電腦連接網路，可以是 Wi-Fi 無線網卡，也可以是 Ethernet 有線網卡。

網卡負責在電腦和網路之間收發資料。網卡本身不等於路由器，也不負責決定整個網際網路的路由路徑。

### 7. 電源供應器 Power Supply

桌上型電腦的電源供應器把市電轉換成電腦元件需要的電力。筆記型電腦通常使用外接變壓器和內部電源管理電路。

電力不穩、散熱不良或硬體故障都可能導致系統不穩定，但不能只憑一次當機就判定電源供應器故障。

## 四、按下電源後，電腦大致如何啟動？

不同品牌和系統的開機細節可能不同，以下是概念流程：

1. 通電：電源系統向主機板和元件提供電力。
2. 韌體啟動：UEFI 韌體開始執行基本初始化。
3. 硬體檢查：韌體初始化必要硬體，並尋找可開機裝置。
4. 啟動載入程式：系統從指定開機裝置載入作業系統啟動程式。
5. 作業系統核心啟動：Windows 載入核心、驅動程式和系統元件。
6. 登入畫面：系統啟動必要服務，顯示登入介面。
7. 使用者登入：桌面和啟動項目逐步載入。

安全意義：如果攻擊者能在作業系統啟動前修改韌體或開機流程，可能造成比一般應用程式更深層的安全問題。因此韌體更新、Secure Boot 和實體設備保護都很重要。初學階段先理解概念，不要為了練習任意修改 UEFI 設定。

## 五、打開 Chrome 時，元件如何合作？

以訪問一個網站為例：

1. 你在鍵盤輸入網址，這是輸入操作。
2. Windows 把鍵盤事件交給相應的系統元件和應用程式。
3. Chrome 的程序在 CPU 上執行指令。
4. Chrome 把目前需要的程式和資料放在 RAM 中使用。
5. 網卡透過 Wi-Fi 或網路線傳送網路資料。
6. 網站伺服器回應資料，Chrome 解析內容。
7. GPU 可能協助繪製頁面，螢幕顯示結果。
8. 瀏覽器快取、下載檔案或使用者資料可能寫入 SSD。

這只是簡化流程。真實系統會有多個程序、執行緒、快取、網路協定和背景服務同時工作。

## 六、為什麼這些知識與網路安全有關？

網路安全並不是只使用掃描工具。許多安全問題都與電腦基本元件有關：

- 惡意程式會以程序執行，並使用 CPU 和記憶體。
- 惡意檔案可能被保存到 SSD。
- 權限和程序隔離由作業系統負責管理。
- 網路攻擊和資料外洩需要經過網路介面收發資料。
- 開機層級的攻擊可能涉及韌體和啟動流程。
- 資源耗盡攻擊可能讓 CPU、RAM、磁碟或網路資源過載。

因此，學安全工具之前，先理解系統元件如何合作，才能判斷工具輸出代表什麼。

## 七、Windows 動手實驗：觀察你的電腦

### 實驗目的

在不修改設定、不安裝軟體的情況下，找到 Windows 顯示的硬體資訊。

### 步驟 A：打開工作管理員

1. 同時按下 Ctrl + Shift + Esc。
2. 如果只看到簡化視窗，選擇「更多詳細資料」。
3. 點選「效能」。
4. 左側會列出 CPU、記憶體、磁碟、Wi-Fi 或乙太網路、GPU 等項目（依硬體而定）。

### 步驟 B：觀察 CPU

點選 CPU，記錄：

- 處理器名稱。
- 使用率。
- 速度。
- 核心數和邏輯處理器數（若畫面有顯示）。

CPU 使用率會隨背景程式而變動。短時間上升不代表中毒或故障。

### 步驟 C：觀察記憶體

點選「記憶體」，記錄：

- 已安裝容量。
- 使用中容量。
- 可用容量。
- 已提交（Committed）數值（若有顯示）。

注意：「已提交」不是實際 RAM 使用量的同義詞；它反映系統承諾提供的虛擬記憶體量，可能由 RAM 和分頁檔共同支援。

### 步驟 D：觀察磁碟

點選磁碟，記錄：

- 磁碟型號或名稱。
- 活動時間。
- 讀取速度和寫入速度。
- 容量（若顯示）。

不要因為活動時間短暫達到 100% 就直接認定 SSD 損壞。還需要查看是哪個程序在讀寫、持續多久，以及是否伴隨錯誤。

### 步驟 E：觀察網路

點選 Wi-Fi 或乙太網路，觀察傳送和接收速度。打開網頁時，數值可能變化。

## 九、常見疑問與故障排查

**問題 1：工作管理員沒有顯示磁碟是 SSD 還是 HDD。**

原因：部分控制器或驅動程式不會提供完整媒體類型資訊。可以在工作管理員的「效能」頁查看，或在 Windows「最佳化磁碟機」中查看媒體類型；不要只根據磁碟速度猜測。

**問題 2：CPU 使用率突然升高。**

排查：工作管理員 →「處理程序」→ 點擊 CPU 欄位排序。先找出使用率最高的程序，確認它是否正在更新、解壓縮、播放影片或執行虛擬機。不要直接結束不認識的 Windows 系統程序。

**問題 3：記憶體使用率很高。**

排查：查看哪個程序使用最多記憶體；關閉不需要的應用程式；檢查虛擬機分配了多少記憶體。Windows 也會使用記憶體做快取，所以「已使用」不等於全部被程式永久佔用。

**問題 4：開啟 VMware 後 Windows 變慢。**

原因可能包括：Kali 虛擬機分配過多記憶體或 CPU、宿主機同時執行多個大型程式、磁碟 I/O 很高，或散熱造成 CPU 降頻。下一課會進一步學習 CPU、RAM 和 SSD 的差別。

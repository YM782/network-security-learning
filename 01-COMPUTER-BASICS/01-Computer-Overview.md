
# 01-01｜電腦的基本組成

## 本課目標
能用自己的話解釋電腦如何接收資料、處理資料、暫存資料、保存資料，再把結果呈現出來。

## 1. 電腦不只是螢幕和主機
- 主機板（Motherboard）：連接 CPU、RAM、儲存裝置和其他零件。
- CPU：執行程式指令。
- RAM：暫時保存正在使用的資料。
- SSD/HDD：長期保存系統、程式和檔案。
- GPU：處理圖像、影片和部分平行運算。
- Network Adapter：讓電腦連接有線或無線網路。
- Power Supply：提供電力。

筆記型電腦把很多元件整合在機身內，但基本工作相同。

## 2. 電腦工作的五個環節
用「打開瀏覽器搜尋網站」作例子：
1. 輸入（Input）：你用鍵盤輸入網址。
2. 處理（Processing）：CPU 執行瀏覽器和作業系統指令。
3. 暫存（Temporary Storage）：RAM 保存目前正在使用的資料。
4. 儲存（Storage）：SSD 保存瀏覽器程式、下載檔案和其他資料。
5. 輸出（Output）：螢幕顯示網頁，網路介面收發資料。

這是理解用的簡化流程；真實電腦會同時執行很多工作。

## 3. 生活比喻
把電腦想成辦公室：
- CPU：正在處理工作的員工。
- RAM：員工桌面上正在使用的文件。
- SSD：存放文件的檔案櫃。
- GPU：專門處理圖像的工作組。
- 網卡：對外通訊窗口。
- 作業系統：安排工作、分配資源和管理設備的人。

## 4. 為什麼網路安全需要懂電腦？
惡意程式會以程序形式執行；程序會使用記憶體；檔案會保存到磁碟；網路資料會經過網卡；權限和資源由作業系統管理。安全問題不是憑空發生，而是出現在這些元件和流程中。

## 5. Windows 觀察任務
1. 按 Ctrl + Shift + Esc 開啟工作管理員。
2. 點「效能」。
3. 依次查看 CPU、記憶體、磁碟、GPU 和 Wi-Fi/乙太網路。
4. 記錄每個項目的名稱和使用率，不要修改設定。

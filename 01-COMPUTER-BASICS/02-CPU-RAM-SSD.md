
# 01-02｜CPU、RAM、SSD 有什麼不同？

## 本課目標
理解三個最常見的電腦元件，知道它們如何合作，以及為什麼同時開很多程式可能讓電腦變慢。

## 1. CPU：執行指令
CPU（Central Processing Unit，中央處理器）負責執行程式指令和處理資料。打開瀏覽器、解壓縮檔案或執行命令時，CPU 都會參與。
- CPU 不是用來長期保存照片和文件的。
- CPU 使用率會隨工作量變化。
- 使用率高不一定是故障，也可能正在處理大量工作。

現在不必研究暫存器、指令流水線或快取一致性。

## 2. RAM：目前正在使用的工作空間
RAM（Random Access Memory，記憶體）暫時保存程式正在使用的資料。
同時打開 Chrome、VMware 和 Kali 時，Windows、Chrome、VMware 和 Kali 裡的程式都會使用記憶體。RAM 是易失性記憶體，正常關機後暫存資料通常會消失。

## 3. SSD：長期保存資料
SSD（Solid State Drive，固態硬碟）保存 Windows、程式、文件、圖片、影片和虛擬機檔案。關機後，SSD 中的資料仍會保留。

## 4. 三者如何合作？
簡化流程：
```text
SSD（保存程式和檔案）
       ↓ 載入
RAM（暫存執行資料）
       ↕
CPU（執行指令）
       ↓
螢幕、網路或檔案輸出
```
作業系統還會管理快取、虛擬記憶體和 I/O；現在先掌握基本關係即可。

## 5. 電腦為什麼會變慢？
可能原因：
- CPU 正忙於處理工作。
- RAM 可用空間不足。
- 系統大量使用分頁檔，磁碟讀寫增加。
- SSD 空間不足或磁碟活動很高。
- 虛擬機分配太多資源，宿主機剩餘資源不足。
- 背景程式或系統更新正在工作。

不要只看一個百分比就判斷硬體故障。

## 6. Windows 實驗
1. 開啟工作管理員 → 效能。
2. 記錄 CPU 使用率、記憶體總容量和使用量。
3. 記錄磁碟名稱或類型（若有顯示）。
4. 開啟一個 Chrome 分頁，觀察數字變化。
5. 關閉測試分頁，再觀察一次。

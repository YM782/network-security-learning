
# 10 — 防禦安全與基本監控

網路安全不只有滲透測試。企業也需要人員監控系統、發現異常、處理事件和降低風險。

## 1. 防禦工作在做什麼？

- 保護帳號和設備。
- 維持作業系統與軟體更新。
- 管理防火牆和權限。
- 收集系統日誌。
- 發現異常活動。
- 調查安全告警。
- 備份重要資料並恢復服務。

## 2. Windows 初級防護

先認識 Windows 內建工具：

- Windows Security：查看病毒與威脅防護、防火牆和裝置安全。
- Windows Defender Firewall：控制網路連線。
- Task Manager：查看程序和資源。
- Event Viewer：查看系統、安全和應用程式事件。
- Windows Update：維持系統安全更新。

不要為了學習而關閉 Defender 或防火牆。若某個程式被阻擋，先確認來源和告警內容。

## 3. 什麼是 Log（日誌）？

日誌是系統記錄發生事件的資料。常見欄位包括：

- 時間。
- 事件來源。
- 使用者或程序。
- 事件類型。
- 結果或錯誤碼。

一筆登入失敗紀錄不一定代表入侵；需要結合時間、來源、使用者、頻率和其他事件分析。

## 4. 初步查看 Windows 事件

1. 按 Win + R。
2. 輸入 `eventvwr.msc`。
3. 展開 Windows Logs。
4. 查看 System 和 Application。
5. 點選事件，閱讀 General 和 Details。

先不要清除日誌。記錄事件 ID、時間、來源和完整訊息，再判斷問題。

## 5. 後續工具

- Sysmon：提供更詳細的 Windows 系統活動紀錄。
- Wazuh：開源安全監控與事件分析平台。
- SIEM：集中收集、搜尋和關聯安全事件的系統。

這些工具需要先理解作業系統和日誌概念，再開始部署。現在先學會查看 Windows 內建日誌即可。

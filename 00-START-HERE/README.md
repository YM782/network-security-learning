
# 00 — 如何使用這套課程

## 你現在要做的事只有一件

先學第一課「認識電腦」。不要先打開滲透測試、漏洞利用或進階工具資料夾。

## 每次學習的 5 個步驟

1. 看本章的「這是什麼」。
2. 讀一個生活例子。
3. 在指定系統執行少量命令。
4. 對照自己的輸出，嘗試說出每個欄位的意思。
5. 寫下今天學會的 3 件事和仍不明白的 1 件事。

## 什麼時候可以進入下一課？

不是做完閱讀就算完成。至少做到：

- 能用自己的話解釋本課最重要的概念。
- 能在自己的 Windows 或 Kali 中重現操作。
- 知道命令在哪裡輸入。
- 遇到不同輸出時，知道先檢查什麼。
- 不依賴複製答案，也能完成小練習。

## 實驗筆記怎麼寫？

不要只貼一張終端機截圖。至少記下：

- 我想知道什麼？
- 我在哪個系統操作？
- 我輸入了什麼命令？
- 結果顯示什麼？
- 我怎麼理解這個結果？
- 如果出錯，錯誤訊息是什麼？

可以使用倉庫中的 [實驗紀錄模板](../templates/LAB-REPORT-TEMPLATE.md)。

## 遇到看不懂的英文或命令

先查本倉庫的中文說明，再查命令的官方手冊。Kali 中可使用：

```bash
man ls
```

按 `q` 離開手冊頁。不要一次背很多命令；先理解目前課程用到的命令即可。

## 重要提醒

學習網路安全不等於可以測試任何網路。只有自己的設備、自己建立的靶場或明確書面授權的範圍，才可以進行測試。


# 08 — Web 網站安全入門

## 課程順序
1. [01 HTTP 請求、回應、Cookie 和 Session](01-HTTP-Request-Response.md)
2. [02 常見 Web 風險與防護](02-Common-Web-Risks.md)
3. 用瀏覽器開發者工具觀察自己的請求。
4. 用 Burp Suite Community 觀察自己建立的測試網站。
5. 到 [PortSwigger Web Security Academy](https://portswigger.net/web-security/) 做初級實驗。
6. 再閱讀 OWASP WSTG 和 Cheat Sheet Series。

## 完成標準
能解釋 HTTP 方法、狀態碼、標頭、Cookie、Session 和權限檢查；能說明 SQL Injection、XSS 和 Broken Access Control 的成因與防護。
